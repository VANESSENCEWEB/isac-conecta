# Relatórios — Diário de bordo do ISAC Conecta

Aqui a gente registra **o que foi feito**, a cada dia trabalhado ou atividade concluída. Não é
burocracia: é o material do **Bloco 5 (Relato do processo)** da entrega — e é o que salva o
grupo quando o avaliador (ou a professora) pergunta "como vocês chegaram nisso?".

## Como usar (simples)
1. Copie `_modelo.md`.
2. Renomeie para a data: **`AAAA-MM-DD.md`** (ex.: `2026-09-18.md`). Um arquivo por dia.
3. Preencha em pt-BR, direto ao ponto. Se várias pessoas trabalharam no dia, cada uma adiciona
   seu bloco no mesmo arquivo do dia.
4. Commite junto com o trabalho: `docs: relatório 18/09`.

## Regras
- **Data no nome**, sempre `AAAA-MM-DD` (ordena sozinho).
- **Curto e honesto** — o que fez, o que decidiu, o que travou. Ninguém lê relatório-romance.
- **Link o que der** — PR, commit, tela, print. Facilita reconstruir a história depois.
- **Decisão vira registro** — mudou de ideia sobre schema/prompt/stack? Anote o porquê aqui.
- **Bloqueio é informação valiosa** — registrar o que travou ajuda o grupo e mostra processo.

## O que NÃO vai aqui
Prompt do motor de IA e sua evolução têm lugar próprio: `docs/dev-kit/skills/prompt-ops`.
Aqui você só linka ("ajustei o prompt v3, ver prompt-ops").
