# ISAC Conecta

Projeto acadêmico de conexão digital com o Instituto Social e Ambiental do Cabo (ISAC).

O ISAC é uma organização sem fins lucrativos do Cabo de Santo Agostinho (PE). Atua em educação ambiental, reflorestamento da Mata Atlântica, inclusão social e defesa de políticas públicas.

Este repositório reúne o material do grupo (escopo, divisão de tarefas, questionário e entregas parciais) e o que for desenvolvido para aproximar o instituto da comunidade — site, fluxos e documentação.

## Objetivo
Facilitar o acesso às ações do ISAC e organizar a entrega do projeto GrowUp / disciplina, com trabalho colaborativo no GitHub.

## Como colaborar
1. Aceite o convite de collaborator.
2. Crie uma branch a partir da `main` (`feat/seu-nome`).
3. Abra um Pull Request. Não commite direto na `main`.
